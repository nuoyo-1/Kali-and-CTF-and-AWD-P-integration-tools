# 不会用时，从这里开始

完整解压最新版后双击启动器，默认打开“新手模式”。先点击“第一次使用？跟着示例试一次”，阅读“准备什么、怎么操作、结果怎么看”，再点击“明白了，开始填写”。示例编码会自动填好，点击“一键执行”。成功后结果文字应出现 flag{hello_ctf_deck}，你可以下载 result.txt 熟悉保存结果的流程。这项示例无需安装第三方软件。

有题目附件但不知道从哪里开始时，选择“我有文件，但不知道用什么工具”，上传文件。平台仅检查文件头和文本特征，提供格式线索与下一步建议，不执行或自动解压附件。识别出图片、抓包、文档或程序后，再回到新手模式选择对应任务。

新手模式有25个任务，覆盖文件识别、图片元数据、ZIP目录、文本Flag、字符串、PDF文字、编码还原、凯撒枚举、文件指纹、抓包协议、HTTP请求、网页在线检查、技术识别、ELF结构、保护检查、源码备份、基线及变化对比。每个任务都说明需要的输入和结果阅读方式。需要第三方工具的任务，若未安装会引导先安装，再回到任务执行；安装后可点击刷新状态。

任务结束不等于已经解出题目。结果窗口提供的是这个操作的阅读提示，日志和结果文件才是此次执行的实际输出。查不到Flag、没有HTTP请求或PDF没有文字都可能是正常情况，按提示检查前缀、输入格式或选择下一项操作。复杂题目仍需要人工判断；平台不会凭空给出漏洞或答案。

之前许多卡片使用相同的类别名称作为大标题，看起来像重复工具。现在大标题用唯一原始软件名，旁边放具体中文功能标签，类别说明放在下方。2751次程序登记中有11个同名命令来自不同软件包，已合并为2740个独立命令按钮；点击同名命令后可以切换软件包来源，原始登记并未删除。完整工具库仍然保留在“Kali全工具”高级页面。

当前52项自动测试通过，新增了格式识别不修改文件、25个新手任务所引用工具有效、同名命令唯一显示且保留来源等检查。浏览器验证了新手模式默认首页、三步引导、演示自动填写、执行与下载列表、781个唯一软件标题和2740个独立命令按钮。Kali上的具体工具、权限、硬件及安装流程仍需实机验证。

新增的GitHub解题任务覆盖RSA公钥、重复XOR、ZIP已知明文、Windows内存进程、Office宏与进阶符号执行。先读准备条件，缺少对应文件或地址时不要直接执行。实际检查范围见 GitHub解题工具与检查结果.md。
