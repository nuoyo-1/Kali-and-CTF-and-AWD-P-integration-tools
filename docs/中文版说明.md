# 中文分类版说明

本版基于全工具版本修改，保留全部 781 个官方目录条目、2751 个程序入口和原来的 CTF 专用预设。工具按用途归入 25 个中文主分类，每个条目只有一个主分类，分类计数合计为781。原始官方类别仍保留在数据中，方便追溯。

分类包括网站与接口、网络发现、域名与公开情报、无线网络、蓝牙、射频硬件、内网与域、密码恢复、加密证书、漏洞研究、远程连接、代理隧道、逆向、移动应用、取证日志、隐写媒体、磁盘恢复、模糊与压力测试、系统审计、云容器、报告协作、开发环境、系统组件、练习靶场和外部自动化助手。分类按钮和下拉框显示数量，列表按分类分组，支持中文功能词和原始名称搜索。

界面使用“中文功能标签＋原始工具名”。137个常见条目有具体中文功能名称，其他条目使用中文用途分类标签，不把不熟悉的专有软件名硬译成误导性的名称。参数区优先显示常用参数的中文标签；无法可靠判断的参数标为工具专用参数，可展开其原始说明。标识符、命令选项、第三方原生窗口和完整官方帮助保留原文，避免改变程序语义。这是平台界面的中文化，不代表第三方所有软件自身都已有中文版。

安装状态分别展示程序可用、包已安装但没有找到程序入口、包未安装、检测失败和资料条目。软件包状态来自dpkg查询，程序是否找到来自PATH检查；检测失败不会被当成未安装。包已安装但入口未找到时，先尝试查找桌面图标或核对官方初始化流程，不需要盲目重装。

Kali默认安装不包含所有官方工具。Kali通过镜像和元包决定初始软件组合，默认镜像、精简安装、ARM、不同安装选项和Everything工具组合的内容不同。目录比默认预装集合大，因此一些工具需要按需安装；平台会复用已存在的程序。参考官方文档：https://www.kali.org/docs/general-use/metapackages/ 和 https://www.kali.org/docs/introduction/what-image-to-download/ 。

当前52项自动测试通过，新增覆盖中文标签完整性、代表性分类、包检测失败时的未知状态，以及包已装但程序入口未找到的状态。浏览器测试通过中文分类导航、中文“蓝牙”搜索（10个条目）、参数表单、原有执行流程和响应式布局。Kali实际包安装、GUI、权限和第三方工具具体业务操作仍需用户在Kali验收。

分发包为dist/Kali-Deck-Chinese.zip，复制到Kali并完整解压后，双击启动工具台.desktop。请使用新解压目录，避免与旧版本文件混用。第三方源码依旧保存在压缩包内，没有在Windows展开。review目录仅用于代码审查，不包含在分发包中。
