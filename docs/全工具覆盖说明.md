# V2 全工具覆盖与验证

范围是本地保留的 Kali 官方 all-tools 索引快照中的全部 781 个条目，已逐页采集成功，未把“全 Kali”混同于所有 APT 库包或全网安全项目。原始索引可能包含导航页；top-100 没有独立包名或程序。官方后续新增条目需要维护者更新索引并重新采集。

本版新增 1382 个包安装入口、2751 个程序入口，其中 1919 个程序有可以生成选项表单的帮助文本；其余程序提供位置参数、交互会话或原生窗口启动方式。33 个官方条目没有列出独立程序，保留包管理、发现已安装图形入口和官方配置说明。当前74个专用CTF预设是独立的便捷入口，不与全目录登记数简单相加。

所有选项及程序与软件包的关系来自对应官方页面，并经过结构校验。选项名称不可通过请求任意替换；实际参数以数组交给 subprocess，不经过 Shell 拼接。位置参数有顺序切换和文件选择器；帮助没有列出或解析器没有识别出的选项，当前不能在通用表单中选择。自动推断选项类型可能不准确，用户可校正“有值”，对照原始帮助确认含义。通用表单不能替代所有工具的业务知识、数据库初始化、驱动配置和服务向导。

新增交互输入接口；普通Linux任务通过PTY收发，Windows本地测试通过管道验证。系统授权运行经pkexec对登记程序及参数提权，平台不接收密码；提权任务不被强制中止，也不允许平台在它运行时正常关闭。原生图形入口从已登记软件包的dpkg文件清单中发现，使用gio打开，不接受外部任意桌面文件路径。

当前52项自动测试全部通过，覆盖781项无遗漏、全部文档采集成功、每个程序属于其页面列出的安装包、选项解析、参数边界、交互会话输入输出和桌面入口来源限制，以及原有平台功能。真实浏览器检查通过：全目录781个条目渲染、aircrack-ng程序表单打开与添加选项，原有编码任务、结果、搜索、目录选择和响应式检查继续通过。截图为docs/preview.png及docs/preview-mobile.png。

这些是登记和平台执行通道的验证，不是2751个外部程序的Kali实测结果。Windows无法验证Kali的APT、图形授权、PTY控制终端细节、硬件、所有程序选项和数据库服务。界面显示“本机已检测”只表示发现软件包或PATH程序；不会把它显示为“实际执行验证通过”。Kali验收时应从本机已经安装的软件开始逐项验证。

全目录资料保存为结构化JSON，第三方源码压缩包保持不解压。新分发包为dist/Kali-Deck-Chinese.zip，内部含逐文件哈希清单，外部含整体SHA-256。传输到Kali后完整解压并双击启动器即可；不要求用户安装Codex或手工修改平台代码。

GitHub扩充另新增6个项目的12个专用功能，不改变官方目录781项与2751次程序登记的口径。真实工具样例验证与安装边界详见 GitHub解题工具与检查结果.md。
